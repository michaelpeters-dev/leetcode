# Codeforces

My Codeforces solutions, migrated into the central competitive-programming store.

- Flat files are named by problem id (e.g. `1679A.cpp`).
- Topic folders (`CompleteSearch/`, `GettingStarted/`, `sorting/`, …) hold study/practice code.
- `practice/` holds local-only working copies not previously pushed.

Solutions are the source `.cpp` only — compiled binaries are intentionally not tracked
(see the repo `.gitignore`).
